# Pathview

Pathview 是一个仅使用 Go 标准库的直线 G-code 预览工具。它把文本程序解释为毫米制物理路径，写出逐段 CSV 和汇总 JSON，不连接、驱动或模拟任何真实设备。

## 用法

```sh
go run ./cmd/pathview -input program.gcode -output ./result
```

成功后会在输出目录生成：

- `segments.csv`：每个实际运动段一行。
- `summary.json`：快速/加工长度、最终物理位置和三维包围盒。

输入非法时进程以非零状态退出，并且在创建输出目录之前终止，因此不会为本轮运行生成结果。

## 支持的程序

仅处理 X、Y、Z 三个轴和以下 G 指令：

- `G0`：快速直线运动，段类型记录为 `G0`。
- `G1`：加工直线运动，段类型记录为 `G1`。
- `G90`：绝对坐标。
- `G91`：增量坐标。
- `G20`：英寸单位，按 `1 英寸 = 25.4 毫米` 换算。
- `G21`：毫米单位。
- `G92`：重设当前物理点对应的逻辑坐标，不产生运动。

初始状态为物理位置 `(0, 0, 0)`、坐标偏移 `(0, 0, 0)`、毫米、绝对坐标、`G0` 模式。运动模式、距离模式和单位模式都会保持，直到被后续指令更改。

## 坐标语义

- 绝对运动：物理终点 = 当前偏移 + 程序坐标。
- 增量运动：物理终点 = 当前物理位置 + 程序位移；不使用坐标偏移。
- 同一行的 `G20`/`G21` 与 `G90`/`G91` 先于该行轴值生效。
- 未给出的轴保持当前物理位置。
- 有轴词但未给 `G0`/`G1` 时，使用当前运动模式生成路径段。
- 只有模态设置、没有轴词的行不生成路径段。
- `G92` 至少指定一个轴，不能与 `G0` 或 `G1` 出现在同一行；未提及轴的偏移不变。
- 零长度运动也会写入 CSV，长度为零，并计入对应类型长度。

## 词法与错误

词由一个字母和有限十进制数组成，例如 `X1`、`y-2.5`、`G01`、`G20G91X.5`。字母忽略大小写，词之间可以没有空格。空行和非嵌套圆括号注释（如 `(note)`）会被忽略。

以下情况会报错并在错误信息中给出至少一行号：

- 未知词或不支持的 G 指令。
- 圆括号注释未闭合或嵌套。
- 同一行重复出现同一个轴词。
- 同一模态组出现冲突指令，如 `G0 G1`、`G20 G21`、`G90 G91`。
- `G92` 缺少轴词，或与运动指令同行。

## 输出格式

`segments.csv` 的列为：

`line`, `motion`, `start_x_mm`, `start_y_mm`, `start_z_mm`, `end_x_mm`, `end_y_mm`, `end_z_mm`, `length_mm`

长度为起终点在毫米制三维空间中的欧氏长度。`summary.json` 的包围盒包含初始物理位置以及所有运动终点。

Pathview 只做几何预览，不估算加工时间、速度、加速度或任何设备动力学。
